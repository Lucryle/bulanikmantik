## Original Paper
C. Li, W. Zhao, L. Zhao, L. Ju, and H. Zhang, "Application of fuzzy logic control theory combined with target tracking algorithm in unmanned aerial vehicle target tracking," *Sci. Rep.*, vol. 14, Art. no. 18506, 2024, doi: [10.1038/s41598-024-58140-5](https://doi.org/10.1038/s41598-024-58140-5).

## Problem Description
A UAV with a downward camera has to find a moving target and stay above it.
A detector gives the target's pixel position; the controller turns the pixel
offset (Δx, Δy) from the image centre into a yaw-rate and a forward-speed
command. The paper solves this with two Interval Type-2 fuzzy logic
controllers (IT2-FLC), a Vision Transformer detector, a particle filter and
edge computing, and reports shorter capture time and lower tracking error
than a PID controller.

This project
1. **reproduces** the fuzzy control layer of the paper in a Python simulation,
2. **checks** the paper's numbers (`docs/PAPER_VERIFICATION.md`),
3. **extends** the controller with a second input (error derivative) and
   studies it with controlled experiments and ablations.

## Method
Minimum reproduction scope (what is rebuilt from the paper):
- the two single-input IT2-FLCs (5 rules each) with the paper's three
  membership-function settings (Benchmark, Setting 1, Setting 2),
- a particle filter that estimates the target position from delayed, noisy
  detections,
- a PID baseline with the same inputs/outputs,
- the paper's three scenes (A fast target, B obstacles + lighting change,
  C motion-mode change) and the three wind speeds (4.9, 9.6, 12.1 m/s),
- the paper's metrics: capture time, tracking error, robustness index.

The Vision Transformer and the edge hardware are replaced by a simulated
detector (Gaussian pixel noise, missed detections, false positives, 0.1 s
latency). Every value the paper does not give is an explicit, configurable
assumption: [docs/ASSUMPTIONS.md](docs/ASSUMPTIONS.md).

## Fuzzy System Architecture
```
camera image ─► detector ─► particle filter ─► project estimate into image ─► Δx, Δy
                                                                              │
             k_x = Δx / x_c ─► IT2-FLC (yaw)   ─► yaw rate  r ∈ [−π/3, π/3] rad/s
             k_y = Δy / y_c ─► IT2-FLC (speed) ─► speed     v ∈ [−2, 2] m/s
```
Each IT2-FLC: fuzzification with interval type-2 triangular MFs → rule firing
intervals (min t-norm) → Karnik–Mendel centre-of-sets type reduction →
y = (y_l + y_r) / 2. Code: `src/fuzzy/membership.py`, `src/fuzzy/type_reduction.py`,
`src/fuzzy/it2_flc.py`.

**Input MFs** (paper, 0–28 scale, normalised with k = (u − 14) / 14):

| Term | Benchmark | Setting 1 | Setting 2 |
|---|---|---|---|
| NB | (0, 5, 10) | (0, 6, 12) | (0, 4, 10) |
| NS | (3, 8, 13) | (4, 9, 14) | (3, 7, 12) |
| MM | (8, 13, 18) | (9, 14, 19) | (7, 12, 17) |
| PS | (13, 18, 23) | (14, 19, 24) | (12, 17, 22) |
| PB | (18, 23, 28) | (19, 24, 29) | (17, 22, 28) |

FOU (assumed, A14): upper MF (a−δ, b, c+δ), lower MF (a+δ, b, c−δ) with height 0.8, δ = 0.05.

**Paper's rules (5 per controller):**

| Input | NB | NS | MM | PS | PB |
|---|---|---|---|---|---|
| Yaw output | LB | LS | ZO | RS | RB |
| Speed output | GB | GS | ZO | BS | BB |

**Proposed IT2 fuzzy-PD (25 rules):** inputs e and ė; rule (i, j) → output
term clip(i + j − 2, 0, 4) (Mac Vicar-Whelan table):

| e \ ė | NB | NS | ZO | PS | PB |
|---|---|---|---|---|---|
| **NB** | NB | NB | NB | NS | ZO |
| **NS** | NB | NB | NS | ZO | PS |
| **MM** | NB | NS | ZO | PS | PB |
| **PS** | NS | ZO | PS | PB | PB |
| **PB** | ZO | PS | PB | PB | PB |

## Dataset
No dataset is used. All data is generated by the simulation (`src/sim/`):
target paths, detector noise and wind are drawn from seeded random streams.
Tuning uses seeds 1000–1009; all reported results use the separate test
seeds 0–29, identical for every controller (paired comparison).

## Proposed Extension
The paper's controller has one input and 5 rules, so it is a nonlinear
P controller: it cannot tell a growing error from a shrinking one. The
extension (IT2-FPD) adds the filtered error derivative ė as a second input
with a 25-rule table (above), keeping the paper's MFs for e so that the effect
of ė is isolated (assumption A22).

## Experimental Results
**Reproduction: paper IT2-FLC vs PID** (scenarios A+B+C pooled, 30 seeds each,
`results/tables/repro_vs_paper.md`):

| Metric | Paper PID → FLC | Our PID → IT2-FLC |
|---|---|---|
| Capture time | 5.2 → 4.2 s (−19.2 %, abstract) / 4.8 → 4.2 s (−12.5 %, Table 3) | 17.01 → 15.27 s (−10.3 %) |
| Tracking error | 0.80 → 0.68 m (−15.0 %) / 0.75 → 0.68 m (−9.3 %) | 0.886 → 0.774 m (−12.6 %) |

The direction of the paper's result is reproduced: the IT2-FLC captures the
target faster and tracks it more closely than PID. The gain is largest in
scenario B (noise, false detections, occlusions): capture time −22 %
(p = 0.029), tracking error −28 % (p < 0.001). Absolute values differ from
the paper because our simulation is not the paper's real flight setup.

**Extension: proposed IT2-FPD vs paper IT2-FLC** (`ext_baseline_vs_proposed.md`):

| Metric | Paper IT2-FLC | IT2-FPD | Change |
|---|---|---|---|
| Capture time (s) | 15.27 | 17.38 | +13.9 % |
| Capture rate (%) | 84.4 | 76.7 | −9.2 % |
| Tracking error after capture (m) | 0.804 | 0.868 | +8.0 % |
| Robustness index, std (m) | 0.452 | 0.405 | −10.4 % |
| Mean error, whole trial (m) | 1.982 | 1.940 | −2.1 % |
| Execution time (ms / step) | 0.672 | 0.975 | +45 % |

The derivative input makes the tracking **smoother** (lower error spread,
better in scenario C with sudden turns: 100 % capture rate) but **not
faster**: in scenario A (fast target) it captures later and less often. The
paper's controller remains the better choice overall in our simulation; this
negative result is analysed in the report.

**Ablations, in short:**
- Type-2 vs Type-1 (E2): for the paper's controller the difference is not
  significant; for the PD controller Type-2 captures clearly faster in
  scenario A (−21 %, p < 0.001).
- FOU width (E3): the paper's controller is insensitive to δ; the PD
  controller only works for small δ (≤ 0.1).
- Noise (E4): at 40 px pixel noise the paper's IT2-FLC keeps a 50 % capture
  rate, PID 10 %, IT2-FPD 3 %.
- Particle filter (E5): without it the IT2-FPD capture rate drops from 100 %
  to 50 % (the derivative amplifies raw measurement noise).
- Type reduction (E6): Nie–Tan gives the same accuracy as Karnik–Mendel at
  less than half the computation time (0.31 vs 0.71 ms / step).

## Limitations
- Simulation only: planar UAV kinematics, no real flight, no real detector.
- The wind model is a residual drift (α = 0.04, assumption A8), so the
  absolute effect of wind is an assumption.
- Many parameters are not given in the paper (FOU, output MFs, Δx MFs, PID
  gains, particle filter); our choices are listed in `docs/ASSUMPTIONS.md`.
- The paper's own numbers are partly inconsistent
  (`docs/PAPER_VERIFICATION.md`), so only relative improvements are compared.
- The CNN / DQN / MPC baselines of the paper are not reproduced.
